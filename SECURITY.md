# Security policy

## Supported version

Security fixes are applied to the latest revision of the default branch. This experimental project does not currently maintain older release branches.

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting for this repository instead of opening a public issue. Include:

- affected commit or release;
- impact and required preconditions;
- minimal reproduction steps;
- whether credentials, screen capture, input injection, archive extraction, protocol handling, or sandboxing are involved;
- a proposed mitigation, if known.

Do not include real credentials, tokens, cookies, private prompts, personal files, or unrelated user data. Use synthetic examples and redact logs.

If private vulnerability reporting is unavailable, contact the maintainer through the private contact method listed on their GitHub profile and disclose only enough information to establish a secure channel.

This policy covers original code in this repository. Vulnerabilities in OpenAI products should also be reported through OpenAI's official security process.
